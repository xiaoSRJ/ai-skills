# Easy AI Skills: Curated Directory of AI & Agent Skills

[简体中文](README.md) · [English](README.en.md)

### 📖 What is this project?
This project collects, organizes, and curates highly practical, business-scenario-driven **AI Skills** from GitHub (including Claude plugins, Cursor rules, MCP servers, and more).

### 💡 What problems does it solve?
While GitHub is flooded with scattered AI projects, most are just underlying technical demos. This project strictly focuses on **"actual business pain points"**. It filters out practical AI automation workflows that you can immediately equip your AI with for scenarios like cross-border marketing, e-commerce product selection, and content distribution.
Our goal is to **drastically reduce your screening cost**, telling you exactly **which Skill to equip your AI with and how to use it** at every specific operational node.

### 🎯 Target Audience
Cross-border e-commerce sellers, overseas social media matrix operators, independent store (DTC) owners, and super-individuals looking to build personal automation workflows using AI IDEs (like Cursor / Windsurf / Claude Code).
