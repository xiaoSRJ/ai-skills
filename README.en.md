## ❓ FAQ

**What are AI Skills?**
AI Skills are pre-packaged instruction sets. Once installed into Claude Code / Cursor / Windsurf, your AI "learns" a concrete business skill (writing viral copy, editing videos, scraping competitor data…) without you writing prompts from scratch.

**What's the difference between AI Skills and MCP?**
Skills govern *how* the AI behaves (workflows); MCP governs *what* it can call (tools & data interfaces). This directory covers both — the prerequisites column tells you which you need.

**How do I install these Skills?**
`/skill add xxx` in the tables is the official Claude Code install command — run it inside Claude Code. Entries marked npm / pip / docker install with the respective command.

**Are these tools safe?**
Third-party Skills may access the network or read local files. Please read [SECURITY.md](SECURITY.md) before installing: never hardcode API keys, test social-media tools on fresh accounts first, and don't run code you can't read.

**Why the weekly automated verification?**
Upstream projects get abandoned or blocked all the time. Every listed project is re-checked weekly for recent activity and accessibility (see [STATUS.md](STATUS.md)), and anything suspicious gets flagged immediately.

**Is data scraping compliant?**
Respect each website's `robots.txt`, platform terms, and local laws — only collect data you're entitled to. This directory makes compliant businesses more efficient; it doesn't teach you how to bypass limits.
